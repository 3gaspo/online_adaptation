\section*{Current evidence}
No current-code cluster experiment has completed and been analyzed.
Consequently there is no accuracy conclusion, selected ablation value, or
claim that online adaptation improves a frozen backbone.

\section*{Implemented protocol}
The project precomputes T0, T1+T2, and T3 indexes before extraction. Each query
retrieves from mature origins only, and ridge or gate fitting uses exactly 10
already matured dates for the query user by default. Retrieval considers at
most 10,000 candidate windows across users. The default scopes remain
all-user raw Euclidean retrieval, same-user fitting, and non-fixed datastore
and training sets; explicit fixed variants and all-user fitting remain
available.

At every forecast, the oldest 80\% of the causal fitting window trains
candidate ridges and the newest 20\% selects
$\alpha\in\{10^{-1},10^{-2},10^{-3}\}$ and
$K\in\{1,5,10,15\}$; the chosen pair is refitted on the complete fitting
window. CSV NaNs are filled with zero after aggregation unless
\texttt{missing\_values=error}; infinite values are rejected.

Extraction is persistent and independently manifested, so matched adaptation
parameters can reuse matching features. Reports require identical query dates.
The fixed-protocol ablation crosses explicit fixed-datastore and
fixed-training-set booleans while retaining the same T3 grid.
